## 1.1.0 — 2026-11-14

### 修复

- 修复了 PTC 模式下，面板会被默认等待规则强行掐断的问题。
- 修复了工具调用方在给选项自行编号时，面板重复编号和顺序混乱的问题。
- 修复了面板静默降级、多条目被截断的问题。
- 修复了相对 persist 落到 profile 目录的问题。

### 变更

- 优化了多选的调用逻辑。
- 现在默认 1 条也走批阅面板（相比原生多一栏备注、且不会被掐断），只在面板不在线 / 用户手动调高阈值时降级为原生面板。

### 已知

- batch_review 暂不支持 plan-review / 审批类 intent。

### Fixed

- Fixed the panel being cut off by the default wait rule in PTC mode.
- Fixed duplicated numbering and scrambled order when the caller numbers the options itself.
- Fixed silent panel degradation truncating multi-item reviews.
- Fixed relative `persist` paths landing in the profile directory.

### Changed

- Reworked multi-select handling.
- A single item now uses the review panel by default too (it adds a note field and
  cannot be cut off); the native card is only a fallback when the panel is offline
  or the user raises the threshold.

### Known

- `batch_review` does not support plan-review / approval intents yet.
